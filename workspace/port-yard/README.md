# 港口集装箱堆场管理系统

管理箱号、船期、堆位和进出闸记录，支持预约进场、堆位自动分配、超期箱提醒和提箱校验。

## 技术栈

- **前端**: React 18 + Vite + React Router（端口 5173）
- **后端**: FastAPI + SQLAlchemy（端口 8000）
- **数据库**: 默认 SQLite 本地模拟（`backend/yard.db`）；切换 PostgreSQL 只需设置环境变量：
  ```bash
  export DATABASE_URL=postgresql://user:password@localhost:5432/yard
  ```

## 快速启动

```bash
# 后端（首次启动自动生成模拟数据）
cd backend
pip install -r requirements.txt
python3 -m uvicorn app.main:app --port 8000

# 前端
cd frontend
npm install
npm run dev
```

或运行 `./start.sh` 一键启动。访问 http://localhost:5173 ，API 文档见 http://localhost:8000/docs 。

## 功能模块

| 页面 | 功能 |
|---|---|
| 运营看板 | 在场箱量、超期箱数、堆场利用率、今日进出闸统计、超期箱提醒列表 |
| 集装箱管理 | 箱号登记（ISO 6346 校验）、状态/堆位/在场天数查询、扣箱/解扣 |
| 船期管理 | 船名航次、ETA/ETD、靠泊/离港状态流转 |
| 堆位图 | A/B/C 三区可视化占用情况，点击占用格查看箱信息，支持移箱（指定空位/指定区/系统自动），移箱记录可追溯 |
| 闸口作业 | 进闸（校验预约及时段→自动分配堆位）、出闸（提箱校验）、进出闸记录 |
| 进场预约 | 创建/取消/改期预约，到场时段=计划时间±容差，过期预约单独筛选，未登记箱号自动建档 |

## 核心业务规则

- **预约进场**: 进闸须存在待进场预约且当前在到场时段（计划时间±容差）内；早到拒绝"未到预约时段"，迟到拒绝"已过预约时段"，均留痕；已出场箱可重新预约回场，在场箱不可重复预约
- **预约改期**: 待进场预约（含已过期）可直接改期到新时段，原时段立即释放；同一箱仅允许一条待进场预约，取消或改期后才可占用新时段
- **过期预约**: 超过到场时段未进场的预约自动标记"已过期"，在预约列表和运营看板单独可查
- **堆位分配**: 进闸时按 区→排→列→层 顺序自动分配空位（已有预分配则沿用），堆场满则拒绝进场；预分配仅限未进场箱，可随时释放，杜绝堆位被永久占用
- **移箱**: 仅在场箱可移；可指定确切空位、指定区自动找位或全场自动找位；目标位被占用即拒绝；每次移箱写入移箱记录（箱号、原堆位、新堆位、原因、时间）
- **超期提醒**: 在场时间超过免堆存天数（free_days）的箱自动标红并汇总到看板
- **提箱校验**: 出闸需满足 ①箱在场 ②无扣箱 ③提箱单号有效（≥6位），任一不满足即拒绝并留痕

## 模拟数据

首次启动自动写入：3 个堆区（216 个堆位）、4 条船期、40 个集装箱（25 在场含 7 个超期、8 已出场、7 已预约）、7 条待进场预约及配套闸口记录。删除 `backend/yard.db` 后重启即可重置。
